## 3. Instructions de réalisation du devoir

### Étape 1 — Récupérer le projet

Rendez-vous sur le dépôt GitHub officiel communiqué par le formateur.

Si vous disposez des permissions nécessaires, clonez le dépôt et travaillez sur une branche dédiée. Si vous n'avez pas les permissions d'écriture, créez un fork du dépôt et travaillez dans votre fork.

### Étape 2 — Créer votre branche

Utilisez la convention de nommage suivante :

`Bootcamp_F01__votre_nom`

Exemple :

`Bootcamp_F01__jean_doe`

Si vous utilisez un fork, créez cette branche dans votre fork.

### Étape 3 — Réaliser le travail demandé

- Répondez aux 10 questions du catalogue.
- Complétez cette fiche de suivi.
- Suivez le cours complémentaire indiqué par le formateur.
- Ajoutez la preuve de réalisation demandée.

### Étape 4 — Enregistrer et pousser vos modifications

Exemple de commandes :

```bash
git status
git add .
git commit -m "docs(F01): complete Git and GitHub assignment"
git push -u origin Bootcamp_F01__votre_nom
```

Vérifiez que `origin` pointe vers le dépôt dans lequel vous avez créé votre branche.

### Étape 5 — Créer une Pull Request

Sur GitHub :

1. Ouvrez votre dépôt ou votre fork.
2. Sélectionnez votre branche de travail.
3. Cliquez sur **Compare & pull request** ou ouvrez une nouvelle Pull Request.
4. Utilisez un titre explicite, par exemple : `F01 - Devoir GitHub - Jean Doe`.
5. Décrivez brièvement le travail réalisé.
6. Vérifiez les fichiers modifiés et la branche de destination.
7. Soumettez la Pull Request pour revue.

**Ne fusionnez pas vous-même la Pull Request**, sauf autorisation explicite du formateur.
