# F03 — Comprendre le Web

**13Layers Academy · Roadmap DevOps · Formation F03**

## Formation unique et obligatoire

Suivez intégralement le cours OpenClassrooms : **[Comprendre le Web](https://openclassrooms.com/fr/courses/1946386-comprendre-le-web)**.

Le cours aborde l'origine du Web, les langages du Web, le fonctionnement du réseau et les métiers du Web. Il comporte **4 quiz**.

**Aucun exercice, questionnaire, TP ou script supplémentaire n'est demandé par 13Layers Academy dans F03.**

## Livrables obligatoires

1. Suivre tous les chapitres et terminer la formation OpenClassrooms.
2. Valider **les quatre quiz** et obtenir leur statut **au vert**.
3. Fournir **une ou plusieurs captures d'écran lisibles** prouvant **tous les quiz au vert** et la **formation terminée**. Si cela n'est pas visible sur une seule capture, joindre plusieurs images.
4. Dans **votre fork personnel**, créer un dossier `formations/F03-Comprendre-le-Web/devoirs/prenom-nom/preuves/` contenant les captures.
5. Créer une **Pull Request** pour demander la validation pédagogique en suivant les [consignes GitHub](CONSIGNES_REMISE.md).

**Important : NE PAS pousser ni fusionner directement sur `main`.** Chaque étudiant travaille depuis **son fork** sur sa branche `Bootcamp_F03__prenom_nom`.

## Critères de validation
- Le cours « Comprendre le Web » est terminé ;
- Les quatre quiz sont validés au vert ;
- Les preuves sont lisibles et sans données sensibles ;
- Les captures sont dans le dossier F03 de l'étudiant ;
- La branche et la Pull Request sont conformes.

La revue est réalisée par le formateur. **Une PR de devoir peut être validée puis fermée sans fusion sur `main`** pour conserver les supports propres.
