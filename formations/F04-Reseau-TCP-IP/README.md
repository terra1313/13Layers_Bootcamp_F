# F04 — Concevez votre réseau TCP/IP

**13Layers Academy — Roadmap DevOps**

## Objectif

Comprendre et concevoir un réseau TCP/IP simple en milieu professionnel : architecture physique, communication, adressage IP, routage, DHCP et DNS.

**Cours obligatoire : [Concevez votre réseau TCP/IP — OpenClassrooms](https://openclassrooms.com/fr/courses/6944606-concevez-votre-reseau-tcp-ip)**. Durée annoncée par OpenClassrooms : environ **10 heures**. L'outil Cisco Packet Tracer est présenté dans le cours.

## Travail demandé
1. Suivre **l'intégralité** du cours OpenClassrooms.
2. Valider ses **3 quiz** : architecture physique, configuration de la communication et ajout de services. Les trois doivent apparaître **au vert**.
3. Fournir une ou plusieurs captures d'écran lisibles prouvant **le cours terminé ET les 3 quiz réussis**. Si une seule capture ne suffit pas, en faire plusieurs.
4. Remplir le document [RAPPORT_REFLEXION_F04.md](RAPPORT_REFLEXION_F04.md) : **10 questions maximum**, simples, situées en entreprise. Répondre avec ses propres mots et des exemples concrets. Pas de projet Packet Tracer supplémentaire imposé.
5. Remettre le tout dans une branche personnelle de **son fork** et ouvrir une Pull Request vers le dépôt officiel. **Aucun push direct ou merge par l'étudiant sur `main`.**
