# F02 — Linux & ligne de commande

**13Layers Academy · Roadmap DevOps · Module F02**

## Objectifs
À l'issue du module, l'étudiant doit savoir :
- naviguer dans l'arborescence Linux et manipuler des fichiers ;
- rechercher du texte avec `grep`, filtres et pipes ;
- comprendre les utilisateurs, groupes et permissions ;
- diagnostiquer les processus, le disque et le système ;
- écrire, rendre exécutable et exécuter un script Bash simple.

## Parcours de la semaine
1. Étudier les notions : terminal, filesystem, `pwd`, `ls`, `cd`, `mkdir`, `cp`, `mv`, `cat`, `grep`, `chmod`, `ps`, `df`, `uname`.
2. Suivre le cours Linux indiqué par le formateur. **Lien : à communiquer par le formateur** (aucun cours précis n'a été validé).
3. Répondre aux [10 questions](01_CATALOGUE_QUESTIONS.md).
4. Réaliser les [6 travaux pratiques](02_TRAVAUX_PRATIQUES.md) dans un environnement Linux personnel (Ubuntu, WSL ou VM).
5. Remettre le travail selon les [consignes](03_CONSIGNES_REMISE.md) et [règles de contribution](../../CONTRIBUTING.md).

## Évaluation sur 100
