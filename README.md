# 13Layers Academy — DevOps Bootcamp

Bienvenue dans le dépôt officiel du parcours DevOps **13Layers Academy**. Les formations sont organisées dans `formations/`.

## Formations

| Code | Formation | Supports | Modalités de remise |
|---|---|---|---|
| F01 | Git & GitHub | [F01](formations/F01-Git-GitHub/README.md) | Questionnaire, preuve et PR |
| F02 | Linux & ligne de commande | [F02](formations/F02-Linux/README.md) | Questionnaire, TP, scripts, preuve et PR |
| **F03** | **Comprendre le Web** | **[F03](formations/F03-Comprendre-le-Web/README.md)** | **Cours OpenClassrooms, 4 quiz au vert, captures et PR uniquement** |
| F04 et suivants | À venir | [Roadmap](ROADMAP.md) | Consignes propres à chaque module |

**Règle fondamentale : jamais de push direct ni de merge non autorisé dans `main`.**

Pour remettre un devoir, créez un **fork**, clonez-le localement, ouvrez le dossier du module puis créez votre branche personnelle avant toute modification. Déposez votre travail dans `formations/FXX-Module/devoirs/prenom-nom/` sur **votre fork**, poussez la branche et ouvrez une PR vers le dépôt officiel. Le formateur peut évaluer et fermer la PR sans fusion.

Lisez le [règlement de contribution](CONTRIBUTING.md) et les consignes de chaque module avant de commencer.
