## Fonctionnement
1. Consultez les consignes du module.
2. Forkez ce dépôt sur votre GitHub.
3. Créez une branche `Bootcamp_F02__prenom_nom` (adaptez le code du module).
4. Préparez vos réponses, scripts et preuves dans `devoirs/prenom-nom/F02/` **dans votre fork**.
5. Ouvrez une Pull Request vers `main` du dépôt de l'Academy pour évaluation. Le formateur valide et peut fermer la PR **sans fusion** pour garder les cours officiels propres.

Les devoirs F01 déjà fusionnés restent temporairement à la racine comme historique. **Ne les supprimez pas.**
